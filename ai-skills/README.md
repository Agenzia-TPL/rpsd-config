# AI Skills

Reusable prompt documents for AI coding assistants. Each subdirectory is an
Agent Skill with a `SKILL.md` entry point.

See `ai-context.md` for instructions on how AI assistants should discover and
use skills.

## Available skills

| Skill | Description |
|---|---|
| [`open-source-it-pa`](open-source-it-pa/SKILL.md) | Publish a repository as open source following Italian PA guidelines (CAD Art. 69 / Developers Italia Annex A) |
